# Reminder feature tour

Use this note while showcasing the reminder features in Crate.

## Views to open

- Inbox: unscheduled capture plus quick additions.
- Today: due today, overdue, and completed-today reminders.
- Upcoming: date-grouped reminders for the configured upcoming window.
- Browse: project cards, counts, progress, and colors.
- Project detail: reorder active reminders and reveal completed reminders.

## Seed data highlights

- `Crate Demo` has recurring reminders, descriptions, links, and completed items.
- `Personal/Health` demonstrates nested project names from nested reminder folders.
- `Work` includes priority, timed reminders, and Markdown code in reminder text.
- `Inbox` includes a Markdown link, a dynamic `today` item, and a completed sample.

## Mutations to demonstrate

- Create a reminder in `Errands`.
- Move `Book airport transfer` from `Travel` to `Personal`.
- Edit the due time on `Capture mobile PWA screenshot`.
- Toggle `Triage plugin issue queue`; recurring reminders should advance instead of completing.
- Reorder active reminders inside `Work`.
