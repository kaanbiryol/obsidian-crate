Full installation guide ↗

  1. 1

    Install BRAT

    Find BRAT in Settings → Community plugins.

  2. 2

    Add Crate

    In BRAT, select Add beta plugin and paste:

    kaanbiryol/obsidian-crate

  3. 3

    Connect your server

    Choose Cloudflare or your own server in Settings → Crate.
