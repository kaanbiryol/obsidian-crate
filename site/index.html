Get started

Install the beta.

Crate is in beta, so it installs through BRAT, Obsidian’s tool for beta plugins.

Obsidian 1.13.0+ · Desktop and mobile
Full installation guide →

  1. 1

    Install BRAT

    Find BRAT in Settings → Community plugins.

    Open in Obsidian
  2. 2

    Add Crate

    In BRAT, select Add beta plugin and paste:

    kaanbiryol/obsidian-crate

  3. 3

    Connect your server

    Choose Cloudflare or your own server in Settings → Crate.

    That’s it. Select Sync now to run your first sync.
