Remote files replaced or deleted by sync are kept for 30 days. Open Restore remote file in Crate settings to recover a copy.

Get started

Install Crate.

Crate is currently in beta. Install it through BRAT, then connect your Cloudflare account.

Crate beta

Install and keep up to date with BRAT.

Get BRAT

Requires Obsidian 1.13.0+ and Cloudflare with R2 enabled. Cloudflare usage charges may apply.

  1. 1

    Install BRAT

    Find BRAT in Settings → Community plugins. Install and enable it.

  2. 2

    Add Crate

    Open BRAT’s settings and add a beta plugin. Enter kaanbiryol/obsidian-crate, select the beta release, and install. Enable Crate in Community plugins.

  3. 3

    Connect Cloudflare

    Open Settings → Crate → Connect with Cloudflare. Sign in and create or select your sync server.

  4. 4

    Connect your other devices

    Install Crate through BRAT on each Obsidian device and connect to the same server. Enable reminders to use the mobile app too.
