Your notes stay local in Obsidian. Crate syncs changes through your chosen server to your other devices.

Get started

Install the beta.

Install Crate in Obsidian, then connect your Cloudflare account or your own server for sync and the web app.

Requires Obsidian 1.13.0+. Desktop reading also works without a server. Read the setup guide ↗

  1. 1

    Install BRAT

    BRAT installs and updates beta plugins in Obsidian. Find BRAT in Settings → Community plugins. Install and enable it.

    BRAT’s installation guide ↗

  2. 2

    Add Crate

    In Settings → BRAT, select Add beta plugin. Paste this repository, choose the latest release, and add the plugin. Then enable Crate in Community plugins.

    kaanbiryol/obsidian-crate

  3. 3

    Connect your server

    Open Settings → Crate → Connect with Cloudflare to create or select a cloud server. For self-hosting, select Connect to your server and enter your server address and pairing code.

  4. 4

    Connect your other devices

    Install Crate through BRAT on each Obsidian device and connect to the same server. Use the Crate web app for reading and reminders on your phone.

A few practical details

Before you get started.

What you need to know about cost, hosting, and your data.

Is Crate free?
Crate is free and open source. You cover the hosting: Cloudflare usage charges may apply, or you can run it on hardware you manage.
Do I need a server?
For vault sync and the web app, yes. Desktop Obsidian can save and read articles locally without a server. Choose your own Cloudflare account or a Docker server for connected features. Compare hosting options ↗
What works offline?
Your local notes stay available in Obsidian. The web app caches opened article text for offline reading. Offline saves and changes to your reading library sync when you reconnect. You can also browse previously cached reminders.
Are my notes end-to-end encrypted?
Crate offers optional end-to-end encryption on Cloudflare and self-hosted servers. Enable it in Crate settings and save your recovery key. Without it, your server can read synced content. File paths, sizes, and notification times remain visible either way. Read the encryption guide ↗
