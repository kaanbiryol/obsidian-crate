Data handling

Privacy

This site is static. It has no analytics, cookies, forms, or third-party scripts. The OAuth callback passes Cloudflare's short-lived response directly to the Crate plugin and immediately removes it from the browser address bar.

Crate uses a temporary Cloudflare OAuth token only while provisioning your resources. It does not store that token or send it to a Crate-operated service.

After you connect Crate and start syncing, vault files and attachments are stored in your Cloudflare R2 bucket. By default, Crate syncs on startup, when Obsidian resumes, and every five minutes; you can change those options in Crate settings. Sync metadata, device credential hashes, reminder indexes, and web or push subscriptions are stored in your Cloudflare D1 database. Scheduled reminder state is stored in your Cloudflare Durable Objects.

Push notifications are optional. When enabled, your Worker sends encrypted notification payloads containing reminder text and project names through the push service used by your browser or operating system. The push provider can observe delivery metadata such as the subscription endpoint, timing, and payload size, but cannot read the encrypted payload.

Crate does not provide end-to-end encryption. Your Cloudflare account and deployed Worker can access synced content. Device credentials are kept in Obsidian's secret storage; the reminders web app keeps its scoped session in that browser's local storage for up to 90 days.

The Crate developer does not operate an intermediary sync service and does not receive your vault data. Cloudflare processes data according to the account and resources you control.

Creating a Crate server provisions Worker, R2, D1, and Durable Object resources in your Cloudflare account. Cloudflare plan limits and possible usage charges apply.

Disconnecting a device removes its local credential but does not delete remote data. To erase the remote copy, delete the Crate Worker, R2 bucket, D1 database, and Durable Object resources in Cloudflare. Clear the Crate site's browser data to remove a local reminders web session.
