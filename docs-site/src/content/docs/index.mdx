Crate brings vault sync, reminders, and read-it-later articles to Obsidian. Your notes stay in your vault as ordinary files, so nothing is locked in. For sync and the web app, you run your own Crate server in your Cloudflare account or on your own hardware. There is no Crate account to create.

Use only the features you want. Reading and Reminders stay off until you turn them on.

:::caution[Crate is in beta]
Try it with a vault you don't depend on yet, and keep a separate backup of your notes. [What to know before you start](/docs/getting-started/limits/) covers the practical limits.
:::

## What would you like to do?

| I want to… | Start here |
| --- | --- |
| Keep my whole vault on several devices | Install Crate, choose a host, then connect each Obsidian device below. |
| Save articles in Obsidian | [Turn on Reading](/docs/features/reading/) in Crate settings. Saving on your device doesn't need a server. |
| Keep tasks in my notes | [Turn on Reminders](/docs/features/reminders/) and create a reminder. Reminders on your device work without a server. |
| Read and manage reminders on my phone without Obsidian | Set up a server, then [connect the web app](/docs/features/web-app/). |
| Choose what runs and where | [Manage features and settings](/docs/features/settings/). |

:::tip[Your first sync]
Connecting a server doesn't move any files yet. Run **Crate: Sync now** in Obsidian. If you want Crate to keep syncing on its own, turn on **Settings → Crate → Sync → Automatic sync** on each device.
:::
