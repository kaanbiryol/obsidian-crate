Crate brings vault sync, reminders, and read-it-later articles to Obsidian. Your notes stay in your vault as ordinary files. For sync and the web app, you run a Crate server in your Cloudflare account or on your own hardware. There is no Crate account to create.

Start with the features you need; you can turn the others off.

## What would you like to do?

| I want to… | Start here |
| --- | --- |
| Keep my whole vault on several devices | Install Crate, choose a host, then connect each Obsidian device below. |
| Save articles in Obsidian | [Try Reading](/docs/features/reading/) with its default folder. Local saves do not need a Crate server. |
| Keep tasks in my notes | [Create a reminder](/docs/features/reminders/). Local reminders work without a server. |
| Read and manage reminders on my phone without Obsidian | Set up a server, then [connect the web app](/docs/features/web-app/). |
| Choose what runs and where | [Manage features and settings](/docs/features/settings/). |

Crate is currently a beta; try it with a non-critical vault and keep a separate backup. Read [What to know before you start](/docs/getting-started/limits/) for the practical limits.

:::tip[Your first sync]
Connecting a server does not transfer your files. Run **Crate: Sync - sync now** in Obsidian, then enable **Settings → Crate → Sync → Automatic sync** on each device if you want ongoing automatic transfers.
:::
