---

Open Obsidian's command palette and type **Crate** to see these. You can give any of them a hotkey in **Settings → Hotkeys**.

## Sync

These appear once this device is connected to a server.

| Command | What it does |
| --- | --- |
| **Crate: Sync now** | Sends this device's changes and gets changes from your other devices. |
| **Crate: Stop sync** | Stops a running sync and turns off automatic sync on this device until you turn it back on. |
| **Crate: Show sync activity** | Opens pending changes, conflicts, and sync history. Available without a server too. |
| **Crate: Show file sync history** | Lists earlier versions of the open file so you can compare and restore one. |
| **Crate: Recover deleted file** | Finds a file deleted within your history period and restores it. |

See [Vault sync](/docs/features/sync/) and [History and recovery](/docs/troubleshooting/recovery/).

## Reminders

These need **Enable reminders** turned on.

| Command | What it does |
| --- | --- |
| **Crate: Create reminder** | Opens the new reminder form. |
| **Crate: Open sidebar** | Opens Inbox, Today, Upcoming, and your projects in the sidebar. |
| **Crate: Open reminder project** | Picks a project and opens its reminders. |
| **Crate: Archive completed reminders** | Moves completed reminders into the **Archive** folder, for every project or one. |

See [Reminders](/docs/features/reminders/).

## Reading

| Command | What it does |
| --- | --- |
| **Crate: Add link to reading list** | Saves a link and downloads the article. Needs **Enable reading**. |
| **Crate: Open reading library** | Opens your Reading inbox, favorites, archive, and highlights. |

See [Reading](/docs/features/reading/).
